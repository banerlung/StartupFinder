# StartupFinder Repo

Платформа для поиска кофаундеров и команды для стартапов.

🌐 [startup-finder.ru](https://startup-finder.ru)

## Стек
Node.js · Express · PostgreSQL · Vanilla JS

## Что умеет
- Выкладывай свой проект и вакансии
- Ищи людей для команды по вкладке «Люди»
- Модерация через админ-панель
